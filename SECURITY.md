# Security Policy

Giftwise ist ein Studierendenprojekt im Kurs ISEF01 (IU Internationale Hochschule), live unter [gift-wise.de](https://gift-wise.de).

## Unterstützte Version

Es gibt nur eine aktive Version: der jeweils aktuelle Stand des `main`-Branches.

## Sicherheitslücke melden

Bitte **keine** öffentlichen GitHub Issues für Sicherheitslücken verwenden. Nutzt stattdessen GitHub's private Meldefunktion:

[Security Advisory melden](https://github.com/Projekt-ISEF01-Geschenke-Manager/ISEF01-Geschenke-Manager/security/advisories/new) ("Report a vulnerability" im Security-Tab dieses Repositories).

Wir versuchen, innerhalb weniger Tage zu reagieren.
